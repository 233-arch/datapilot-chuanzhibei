# 疯狂星期四：DataPilot v0.6.5 录屏操作指南

官方AI WEB赛道要求：MP4，5-8分钟，不低于1080p，普通话讲解；覆盖项目介绍、核心功能、AI技术亮点。2026-10-28复核[官方赛道](https://www.boxuegu.com/matchTrack/detail/?id=10037)公开正文。建议成片约7分钟，留出重试与转场余量。本文件是指导材料，不是已录好的视频。

## 录前准备

1. 使用桌面浏览器，窗口最大化；先试浏览器缩放100%，根据实际录出画面调整到文字清晰、图表完整。准备1920×1080横屏录制区域，不能把低分辨率画面放大后冒充1080p。
2. 如公开演示在当前网络返回403，直接运行本机版本。在项目目录打开终端，首次执行 `npm ci --include=dev --include=optional --no-audit --no-fund`，之后执行 `npm run dev`；保持终端运行，浏览器打开终端打印的地址。在线托管迁移不属于本次修复。
3. 开始录制前，在“设置与API”填自己的DeepSeek密钥与账户支持工具调用的模型ID，点击“验证并应用我的API”，看到成功和“已验证”后关闭设置。验证本身消耗少量额度。不要录下输入密钥、剪贴板、环境文件、终端凭据；刷新页面会清除内存配置，需要重新验证。
4. 准备 `docs/samples/innovation.csv`（8行合成表）、`docs/samples/业务口径说明.md`，以及GitHub README和实际CI结果标签页。先演练一遍，了解各按钮位置。所有数据均明确称为合成样本。
5. 关闭无关标签和通知。选择安静环境、耳机麦克风，先录15秒，回放确认声音和文字清晰。不要在正式成片中展示未完成的个人团队资料。

## 怎样录

推荐使用OBS Studio，来源选浏览器“窗口采集”或限定好的“显示器采集”。在“设置 → 视频”把基础与输出分辨率设为1920×1080，30fps；只启用需要的麦克风，避免扬声器回声。先保存MKV，结束后使用“文件 → 录像转封装”转为MP4；OBS官方说明支持内置转封装，避免直接改文件后缀。[OBS录制说明](https://obsproject.com/kb/standard-recording-output-guide)

如果本机已有Xbox Game Bar，也可先聚焦浏览器，按Win+Alt+R开始/结束、Win+Alt+M切换麦克风；文件默认保存在用户“视频/Captures”。先试录确认能捕获当前应用及所需画面，再检查实际分辨率；需要切换多个应用时优先OBS。[微软官方说明](https://support.microsoft.com/en-us/accessibility/windows/use-a-screen-reader-to-record-your-screen-with-xbox-game-bar)

这张时间表是剪辑目标，不是响应速度承诺。可剪去等待和失误，但要保留真实提问、模式、计划确认与结果，不伪造成功、数值或“实时速度”。若知识问答临时不可用，先解决个人API连接后重录该段；不要用静态文字替代真实调用。多步骤助手、手机布局、字典别名可作为备选片段，避免把全部功能挤成难以看清的快速点击。

## 录完检查与交付

- 完整播放一遍：5-8分钟、MP4、至少1920×1080、有清晰普通话音轨；语音与操作对应，页面标题、数值和来源能看清。字幕可选，不替代口播。
- 检查无密钥、密码、私人文件、聊天记录或虚构团队信息；结论与实际模式一致。文件改名建议 `疯狂星期四_数问DataPilot_演示视频.mp4`，以实际提交入口命名要求为准。
- 视频属性可先在资源管理器“属性 → 详细信息”查看；若有ffprobe，执行 `ffprobe -v error -show_entries format=duration:stream=codec_type,width,height -of json "视频绝对路径.mp4"`，核对时长300-480秒、分辨率和音轨。程序无法判断普通话和内容完整性，仍需人工观看。
- 要纳入本项目提交检查，可把实际文件路径填写到本机忽略文件 `submission/review.json` 的 `videoPath`，并在人工观看确认普通话与内容后填写 `videoNarrationVerifiedAt`，运行 `node scripts/check-submission.mjs`。不要把大视频提交进Git，也不要用讲解稿顶替MP4。
