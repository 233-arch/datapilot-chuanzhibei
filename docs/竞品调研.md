以上为交互和能力层面的学习，没有复制其源码、界面素材、商标或闭源实现。开源库与 Sites starter 的使用边界见 `开源与原创说明.md`。

## 定位与差异

通用“上传表格 + 问答 + 图表”已有成熟产品，不能把这一组合本身当作原创突破。DataPilot 更适合大数据本科课程实验与小规模 CSV 探索：以本机确定性计算、明确范围、来源证据、可手算样本、可移植分析口径为重点。业务价值目前是待用户验证的假设，没有虚构访谈、用户量或付费数据。

新增的分析配置迁移使用 SHA-256 指纹绑定同一张表，导出计划、字典、收藏而不导出原始记录；即使列名与行数相同，换了单元格或行顺序也拒绝恢复。此机制提供复现实验和防误用的具体依据，不能等同于对任意数据分析的正确性证明。

## 本轮未盲目扩展的能力

没有为了覆盖评分点而把关键词检索称为向量 RAG，也没有把规则模式称为大模型。多表 Join、任意代码执行、预测、云数据连接、多模态和协作工作区尚未实现。它们需要额外的需求、权限、运行成本和验证，不能只在 UI 中添加入口就算完成。

## 验证方法

新增 12 项测试覆盖字段歧义、长度约束、别名定位、模型上下文、下钻范围、月份分桶、配置指纹、错误数据拒绝、导出防注入与 HTML 口径。浏览器实际编辑字典、使用别名提问、分组继续分析、预览报告，以及导入正确/错误配置。
