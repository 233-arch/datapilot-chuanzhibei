# v0.7.0 本地产品工作流完善

本轮按“保存与恢复 → 图表和助手 → 场景模板与报告 → 稳定性验证”的顺序实施。修改保存在本地；没有发布 Sites、推送 GitHub 或更新参赛提交压缩包。

## 已完成的能力

| 顺序 | 功能 | 使用入口与结果 |
| --- | --- | --- |
| 1 | 项目备份与恢复 | 我的数据集 → 导出当前项目 → 保存备份文件。恢复前显示数据、分析和规则数量，校验文件内容；确认后先保存当前工作，再打开独立项目。 |
| 1 | 报告草稿持久化 | 洞察报告中修改标题、勾选章节、调整顺序、填写“发现／证据／建议”，自动保存在本机。刷新和项目切换后可恢复。 |
| 1 | 报告核验状态 | 核验后标记当前数据、统计口径、规则与报告内容；相关内容变化时提示重新核验。该标记由使用者确认，不代表系统保证业务结论正确。 |
| 2 | 图表操作分层 | 主要控件只保留分组、指标和统计方式，排序、Top N 与时间粒度收起；其他维度图表按需展开。 |
| 2 | 图表交互 | 点击图形先选中分组，再通过来源入口核对记录；保留数值、明细、放大和筛选操作。尊重系统减少动态效果的偏好。 |
| 2 | 页面情境助手 | 根据质量、图表或报告页面提供实际可执行的操作，显示分析范围；添加报告前确认，适用操作可撤销。无需 API 即可使用本地规则能力。 |
| 3 | 两种场景模板 | 首页提供校园消费、零售经营模板。先映射真实字段，预览将创建的图表和必填规则，再应用；避免重复收藏相同计划，可撤销本次配置。 |
| 3 | 报告演示模式 | 洞察报告 → 演示报告，只展示选中章节，包含图表、统计摘要、范围和批注；左右方向键翻页，Esc 退出。 |
| 4 | 存储与模块结构 | 自动保存、图表配置、报告草稿、模板和备份独立成模块。数据载荷与小型配置分开保存，修改标题等配置不重写整份数据。 |
| 4 | 失败保护 | 同一浏览器的多标签页保存冲突会明确提示；存储失败不覆盖上一次成功版本，可先导出当前项目，再重试或载入另一页版本。 |

## 推荐体验路线

1. 在“我的数据集”备份正在使用的项目，点击生成的保存链接取得 `.datapilot.json` 文件。
2. 导入含日期、分类和金额字段的表格，在首页选择一个模板，确认字段映射后应用。
3. 到图表页调整分组和指标，展开高级选项，选中分组并核对来源明细。
4. 打开助手，尝试当前页面的推荐操作；报告添加操作需确认，清洗操作先预览。
5. 到洞察报告修改标题、选择章节、调整顺序，补充发现、证据和建议，完成核验。
6. 刷新网页，确认草稿保留；进入演示模式，用键盘翻页，再导出 HTML 或 Markdown。
7. 在另一浏览器或设备打开 DataPilot，上传项目备份，核对预览后恢复。

### 本机性能基线

20,000 行 × 80 列合成数据，Node v24.19.0 单次测量：

| 操作 | 时间 |
| --- | ---: |
| 数据概况计算 | 253.19 ms |
| 分组聚合 | 14.40 ms |
| 生成备份 | 244.36 ms |
| 校验并解析恢复 | 568.91 ms |

生成的备份为 23,910,341 字节。这是 Node 中的函数基线，**不是浏览器交互延迟、跨设备性能承诺或压力测试结果**。复现：先运行 `node scripts/test-product-workflows.mjs`，再运行 `node scripts/benchmark-product.mjs`。

截图和性能原始结果位于 `outputs/v0.7.0/product-workflows/`：`charts-desktop.png`、`charts-desktop-detail.png`、`charts-mobile.png`、`charts-mobile-detail.png`、`presentation-desktop.png`、`performance.json`。测试和构建日志位于本机 `work/final-product-tests.log` 与 `work/final-product-build.log`。

## 使用边界

- 项目备份包含**当前项目**的数据、分析配置、规则、知识文档和报告草稿；库中其他项目需要分别备份。文件是明文 JSON，不包含应用的 API 凭据，但用户自己写在数据或笔记中的内容仍会随文件保存。
- 备份上限 75 MiB；表格导入限制仍为 25 MB、20,000 行、80 列。备份不是云同步，也不是数据库镜像。
- SHA-256 用于发现意外损坏，不用于证明文件作者或抵抗能够重新计算校验值的攻击者。
- 模板只建立明确的基础分析与必填规则，不推断业务阈值。负值或非正合计不适合饼图时回退为柱图；Top N 结果会注明展示范围。
- 报告核验状态和撤销记录有明确范围；在模板应用之后继续修改配置，不再提供会覆盖这些新修改的旧撤销操作。
- 自动保存有 500 ms 防抖，应等到“已保存在本机”再关闭页面。未完成的浏览器写入、清除站点数据和设备故障仍需外部备份保障。
- 本轮未调用外部模型、未执行真人可用性访谈、未获得新的官方竞赛评分。真人试用应另行邀请参与者，不把自动化验收当作用户研究。
