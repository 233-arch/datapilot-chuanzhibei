# 七分钟演示脚本

至少 1080p，普通话讲解。这是脚本，尚未录制视频。

录制v0.6.3时优先按[录屏操作指南](录屏操作指南.md)安排；本表保留各功能的备选展示顺序。

| 时间      | 操作与讲解                                                                                      |
| --------- | ----------------------------------------------------------------------------------------------- |
| 0:00-0:40 | 展示工作台，说明面向大数据学生和初级分析者，解决表格探索和结果核验问题。                        |
| 0:40-1:10 | 上传 `docs/samples/innovation.csv`，明确为 8 行合成样本，销售额合计 4910。                      |
| 1:10-2:00 | 问“各地区利润合计”，继续“改成均值”“只看华南”，展示 110.25。真实模型未配置时必须说明是演示模式。 |
| 2:00-2:40 | 展开计算口径，点击图表分组查看原始记录，反向联动筛选；说明范围与缺失处理。                      |
| 2:40-3:20 | 重置范围，收藏全部与华东的同一月度分析，改名批注，展示同口径比较。                              |
| 3:20-4:10 | 创新实验室的异常侦探：销售额上界 205，4000 被标记；查看来源，说明异常不等于错误。               |
| 4:10-5:00 | 情景推演选择华东销售额 +10%，展示基线 4910、模拟 4960、变化 50，重置回基线；明确非预测。        |
| 5:00-5:35 | 切换零售合成样本，质量检查、去重和撤销：1251 → 1248 → 1251。说明切换会清空旧收藏。              |
| 5:35-6:10 | 手机布局展示实验室和助手，导出带计算口径的报告。                                                |
| 6:10-7:00 | 展示架构、122项业务/API及交互回归、7项仓库测试与接口检查，说明真实模型评估状态及边界，不虚构成果。                     |

可问：各地区平均利润；华东的产品类别销售额占比；按渠道统计记录数。

录制前连接并验证真实模型，确认评审访问、API 网络和额度。隐藏密钥、私人文件与账号；不要添加没有实测的准确率、延迟或商业数据。
