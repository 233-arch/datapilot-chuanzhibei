# 六分钟演示脚本

至少 1080p，普通话讲解。这是脚本，尚未录制视频。

| 时间 | 操作与讲解 |
| --- | --- |
| 0:00-0:40 | 展示工作台，说明面向大数据学生和初级分析者，解决表格探索和结果核验问题。 |
| 0:40-1:20 | 导入有权展示的 CSV，或明确使用合成数据。核对字段、记录数和质量状态。 |
| 1:20-2:10 | 问“按月查看销售额趋势”“各地区平均利润”。真实模型未配置时，必须说明是演示模式。 |
| 2:10-2:50 | 展开分析依据与口径，切换图表，说明模型规划、确定性计算和缺失排除。 |
| 2:50-3:40 | 质量检查、去重、撤销：合成数据从 1,251 变为 1,248 条，再恢复。 |
| 3:40-4:15 | 表格搜索订单，说明图表可核对数据来源。 |
| 4:15-4:50 | 查看历史分析，导出带来源与计算口径的报告。 |
| 4:50-5:30 | 手机宽度打开助手，展示响应式布局。 |
| 5:30-6:00 | 展示架构和测试，说明真实模型评估与后续扩展状态，不虚构成果。 |

可问：各地区平均利润；华东的产品类别销售额占比；按渠道统计记录数。

录制前连接并验证真实模型，确认评审访问、API 网络和额度。隐藏密钥、私人文件与账号；不要添加没有实测的准确率、延迟或商业数据。
