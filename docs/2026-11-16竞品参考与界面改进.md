# DataPilot 同类产品参考与本地改进

日期：2026-11-16；版本：本地 v0.7.0。

## 参考依据

主要参考 Metabase 与 Hex，补充借鉴 Rows 的问答入口。参考公开的产品介绍和官方文档，不使用其他产品的品牌、素材或源代码。

| 产品与官方来源 | 可借鉴的模式 | DataPilot 的实现 |
| --- | --- | --- |
| [Metabase 查询构建器](https://www.metabase.com/features/query-builder) / [官方操作文档](https://www.metabase.com/docs/latest/questions/query-builder/editor) | 将数据选择、分组和汇总逐步呈现，允许检查结果及计算口径 | 图表编辑器划分配置与结果区域；配置按两步编号；结果标题集中展示记录范围、展示分组、收藏和报告操作 |
| [Hex Threads](https://hex.tech/product/threads/) | 自然语言提问，能够检查分析逻辑，并把对话中的发现继续用于图表和交付 | 首页直接提问，调用现有本地/API 分析；保留计划预览和确认；新增最近分析、收藏入口及直接进入报告的按钮 |
| [Rows AI Analyst](https://rows.com/docs/using-the-rows-ai-analyst) | 结合具体字段提问，用侧栏承接分析过程 | 首页问题输入框、实际字段插入、当前分析范围、推荐问题、Ctrl/⌘+Enter 提交与侧栏结果 |

Metabase 产品页在查阅时显示约 5 万 GitHub 星标；Hex 官网页面列有 StubHub、Brex 等客户实例。Rows 官网目前标示已加入 Superhuman，本轮将其公开文档作为交互参考，不对三者作未经验证的实时热度排名。

## 页面变化

1. **首页**：问题入口位于数据概况之前。问题建议根据当前表的真实字段生成；插入字段只编辑草稿，不自动运行。常见统计无需 API，复杂语义使用个人 API。计划类问题先预览；直接统计答复明确展示本机计算结果。
2. **我的分析**：最近分析与收藏分开查看，显示真实数量和空状态。选择已有分析会恢复该项自己的指标、图表和筛选条件。分类支持点击以及左右方向键、Home、End。
3. **首页收纳**：保留当前分析和最近访问；六个工作模块收进“全部分析工具”，侧栏仍可直接进入各页。场景模板与报告保留在右侧，窄屏纵向排列。
4. **图表页**：结果名称、范围、收藏及报告入口集中在顶部。左栏按“配置分析 / 选择表达方式”组织；计算口径可展开。颜色区分维度、指标与汇总控件，不改变计算规则。
5. **数据集库**：默认文件列表，列出规模、分析资产及保存时间；支持按保存时间、文件名、记录数排序，支持搜索和卡片视图。切换显示方式保留当前搜索与排序。备份迁移收在可展开区域。
