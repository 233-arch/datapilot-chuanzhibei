# 本机数据集库与工作空间完善

本轮针对“导入新文件就丢失上一份分析上下文”的实际使用缺口，完善本机数据管理和应用导航。修改仅保存在本地，不涉及在线发布、GitHub 推送或提交压缩包替换。

## 使用方式

1. 在“我的数据集”点击“保存到数据集库”，保留当前数据与分析配置。已存在时按钮变为“更新库中副本”，更新同一数据集的最新副本。
2. 导入新文件或打开另一份工作时，系统先保存当前副本；存储失败时不切换数据。点击样例数据也使用同样的保护流程。
3. 在库中按文件名搜索，点击“打开工作空间”恢复数据、筛选、图表方案、收藏、最近分析、字段字典、探索路径与工具配置（包括业务规则）。历史结果重新计算，不直接信任旧的缓存数值。
4. 移除副本需要在卡片上确认。移除不删除当前打开的数据，可在本次页面会话内撤销最近一次移除。
5. 同名文件按不同数据集 ID 区分。最多保存 8 份数据集副本；达到上限时提示先整理库，不自动淘汰已有工作。

## 页面与框架

- 数据集页拆为独立的 `DatasetLibrary` 组件，按“当前工作—副本库—导入与本机存储说明”组织内容，移除重复的当前文件横幅和重复导入按钮。
- 数据集卡片展示真实行列数、分析记录、收藏与规则数量；搜索无匹配、首次使用、读取中和保存失败均有对应反馈。
- 短屏幕侧栏压缩装饰和分组标题，保留导航字号；设置、字段字典、帮助固定在底部。较高屏幕仍展示导航分组。
- 数据集页隐藏浮动分析助手，减少对文件操作的遮挡。分析页面保留助手入口。
- 持久化集中在 `local-store`；当前工作写入按顺序执行。副本、索引和切换目标在同一个 IndexedDB 事务中写入，事务失败不会只切换一半。
- `workspace-snapshot` 统一新旧工作恢复、字段校验和历史重算；异常字段配置回退到有效默认值，结构损坏的数据阻止恢复。
- 切换期间阻止重复操作；导入向导等待持久化成功后才结束，错误留在向导内展示。

## 当前边界

数据集库仅属于当前设备、当前浏览器及当前站点来源（域名/端口）。清理浏览器数据会移除副本，不提供跨设备同步。重要原始文件应另行保留。副本不包含 API 密钥；报告勾选、表格视图和撤销历史仍属于临时界面状态。每个数据集保存最新副本，不是无限版本历史。
