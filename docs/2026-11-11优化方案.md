# DataPilot 交互连续性优化方案与实施记录

日期：2026-11-11。范围：本地 v0.7.0，不涉及线上发布、GitHub 推送或提交包更新。

## 目标

上一轮已拆分九个页面。本轮解决切页后重复设置、返回任务入口不明显以及导航反馈不足的问题，保留现有配色、数据计算口径和功能分工。

## 方案与完成情况

| 优先级 | 优化项 | 已实现的行为 | 验收方式 |
| --- | --- | --- | --- |
| P1 | 数据明细操作现场 | 搜索、排序、显示列、每页条数、页码提升到工作空间状态；同一数据集跨页返回后保留 | 搜索华东、销售额升序、每页 25 条、第 2 页、隐藏利润列；离开至质量页再返回，全部保持 |
| P1 | 首页继续任务 | 最近访问的非首页页面作为主入口，另外展示最多三个最近页面；去重并按访问更新 | 首页按钮回到明细，查询保留；刷新后最近页面仍显示 |
| P2 | 导航反馈 | 浏览器标签显示当前页面；切页后焦点进入主标题；未知地址规范化到首页 | 浏览器标题、焦点、无效地址与前进后退核对 |
| P2 | 视觉与手机操作 | 首页新增浅绿继续任务卡、明确主按钮、最近访问按钮；导航和任务按钮有键盘焦点样式 | 1440 × 1000 桌面与 390 × 844 手机检查，手机继续操作与返回正常，无整页横向溢出 |

## 使用方式

1. 在数据明细页设置搜索、排序、显示字段和分页。
2. 使用主导航进入质量检查或其他分析页面。
3. 返回数据明细，或者在首页点击“继续数据明细”，继续之前的核对。
4. 首页“最近访问”可快速回到其他常用任务；浏览器后退同样可用。

## 状态与隐私边界

- 数据明细视图保存在当前应用内存中，刷新网页后重置；不会把搜索内容额外写入浏览器存储或 URL。数据集标识变化时使用默认视图，避免旧字段选择影响新数据。
- 数据范围缩小时，显示页码仍由有效结果数量约束，不出现越界空页。搜索覆盖所有字段，导出保持现有全部匹配结果口径。
- 最近访问使用当前标签页的 sessionStorage，仅保存最多四个已知页面标识；不保存数据、提问或 API 凭据。存储不可用时退回内存状态。
- “最近访问”表示访问记录，不代表某个分析任务已经完成，也不代表恢复已关闭标签页的全部状态。
- 不改变已有数据计算、真实模型调用规则和本机数据存储方式。
