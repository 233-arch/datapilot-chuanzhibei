# 开源依赖、框架与原创边界

项目使用 React、TypeScript、Vinext/Vite、Cloudflare Workers、Recharts、Zod、Lucide 等通用组件和 Sites starter 的部署/认证工具链。项目不是从零实现浏览器框架、图表库、云运行时或认证基础设施，不将这些基础能力作为参赛者的原创成果。

本项目自行实现的业务范围主要为：CSV 数据解析与剖析、受限聚合计划与校验、模型 Function Calling 适配、摘要检索、演示意图匹配、本机持久化、数据质量与清洗、来源回溯、联动筛选、异常计算、情景模拟、收藏对比、字典元数据、同数据配置迁移和离线报告。界面交互与样式围绕这些业务定制。

同类产品调研仅借鉴公开的功能与交互思路，未复制其源码和品牌素材。具体来源与落地差异记录在 `竞品调研.md`。不能承诺这些通用功能构成法律意义的独创性，或预先代表主办方认定。

代码开发使用 AI 辅助。参赛者必须逐模块阅读、运行、解释并核对代码，确认有权提交；不能把机器生成直接等同于已完成个人学习或答辩准备。提交历史如实保留，不补造早期开发记录。

v0.6自行实现本机TF-IDF检索、文档分段、引用校验、工作流编排、状态恢复、指标定义与调用限制。不将通用算法或“上传表格问答”组合本身声称为原创算法突破。

依赖的实际版本及许可证以锁定文件和各包的 LICENSE 为准；分发时保留第三方要求的版权与许可声明。直接依赖列表由 `scripts/dependency-notices.mjs` 生成于 `第三方依赖.md`，不代替完整的间接依赖法律审查。
