# 数问 DataPilot 技术文档

版本 v0.6.8 · 2026-10-29 · AI WEB 网页开发挑战赛 · 疯狂星期四

## 1. 项目概述

数问面向需要做课程实验、探索业务表格的大数据学生与初级分析者，提供“导入数据、自然语言提问、图表探索、核对口径、导出报告”的工作流程，对应 AI 数据分析与可视化方向。

参赛团队：疯狂星期四；学校：河南农业大学；组别：B组；队员：刘宗柯、陈世航、刘兴海；指导老师：唐琦。成员实际分工待参赛者补充。

常见问题包括制作图表耗时、模型口头结论难以核验、样例无法替换为自己的数据。数问将语言理解与计算分开，每个结果可核对字段、聚合方式和参与记录。项目边界为单表探索性统计，不承诺自动发现因果或未计算的预测。

### 1.1 需求分析

目标场景为大数据本科生的课程实验、社团表格统计和小规模 CSV 探索。学生需要降低表达和制图门槛；教师或协作者需要复核样本范围、业务口径与计算结果。当前问题定义来自使用场景分析，尚未完成访谈或用户研究，已提供可执行试用任务表，不填写虚构需求验证。

核心需求为：用户可替换自己的文件；问题映射到真实字段；关键统计可查看来源；相同数据和配置可复现；导出的成果可离线核对。验收以固定合成样本、可手算结果、独立边界测试和浏览器交互为依据。商业推广、真实企业效益与用户增长不作为已实现成果。

## 2. 系统架构

前端为 React 与 TypeScript，桌面三栏工作台，手机使用助手抽屉。图表采用 Recharts，图标采用 Lucide，定制 CSS 实现视觉与响应式。Vinext/Vite 与 Cloudflare Workers 提供同源路由，保留 Sites 托管访问控制。

文件在浏览器完成解析、剖析、清洗与聚合，存入 IndexedDB。服务端只接收问题与字段摘要，在有密钥时调用模型。服务端使用 Zod 与真实字段约束验证计划，浏览器执行前再次检查。

```text
文件 → 解析 → 剖析 → 本机存储
              ↓ 问题 + 摘要
          字段检索 → 模型工具调用 → 校验计划
                                      ↓
                              聚合 → 图表/证据 → 报告
```

## 3. 数据处理

支持 XLSX / CSV / TSV、UTF-8 BOM 和常见中文编码回退。兼容双引号、引号转义、字段内逗号与换行；拒绝列数不一致、重名字段、危险对象字段与超限文件。单文件限制由5 MB提高至25 MB，继续保留20,000行、80列。CSV解码后按UTF-8字节数同样受25 MB限制；原始文件、导入向导和解析使用统一校验，大小提示随配置生成。

推断数值、日期与文本类型。缺失保持 null，数值聚合排除缺失和无效值，均值以有效记录为分母。纯日期保留日历日期，避免时区令月初记录落入前月。完全重复记录默认保留，由用户主动清洗。

完整与去重评分为完整率减去 20 倍重复记录占比，是不计无效值的辅助指标。质量摘要同时检查缺失、重复和无效值；即使辅助分为100，无效数值仍触发警告并在数值聚合时排除。清洗支持去重、首尾空白处理和缺失标记，不擅自用 0 填充。清洗会清空旧分析、筛选和收藏，撤销同时恢复它们。

### 3.1 Excel导入与后台计算

read-excel-file 9.3.12（MIT）在本机Web Worker解析XLSX。导入向导选择工作表与表头行，预览数据，允许指定数值、日期、文本类型。文本订单编号保留前导零；Excel百分比保留底层小数。空白行跳过，重复/空表头、无表头数据和无效转换被拒绝。只读取公式缓存，不重新计算公式。

原文件上限为25 MB；ZIP目录声明展开超过64 MB、超量内部文件、工作表超出20,000行/80列、整体超量单元格或导入行JSON超过30 MB会阻断。展开限制用于限制正常解析规模，不能代替所有恶意文件防护。字段类型覆盖计入配置指纹，避免相同文字数据在不同业务类型下错误复用配置。

导入、剖析和周期分解在可终止Worker执行，切换任务或取消会释放Worker。复用已有剖析结果，避免空筛选和已知字段重复剖析；原有小规模图表聚合仍由确定性引擎执行。浏览器后台任务与托管Cloudflare Worker是两种不同运行环境。

## 4. AI 方案

普通图表助手按字段名、分类值和时间意图匹配，最多选24个字段，此匹配仍为关键词检索。v0.6另实现业务文档的本机稀疏向量检索与引用问答。敏感分类值过滤不能代替正式脱敏；多步骤规划不发送分类高频值，只发送字段与统计摘要。

### 4.1 选型理由、集成方式与优化策略

使用 Chat Completions Function Calling 服务，将语言理解限定为结构化计划，避免执行模型任意代码；访问者在设置中自行填写服务商、模型和个人密钥，默认值不代表已经接通。网页请求不回退使用部署者密钥；本机环境模板仅供独立评测。前端采用 React/TypeScript 保持组件化，Recharts 负责图表，Zod 负责跨边界结构校验。本项目自行实现业务计算，而非包装已有数据分析平台。

提示词把用户问题、数据摘要与业务定义视为不可信输入，要求调用固定工具，不生成统计数字。输入限制为 2000 字问题、80 个原字段、最多 24 个检索字段；上下文优先保留上一轮维度、指标与筛选字段。模型超时 45 秒，限制输出长度并校验字段、枚举和 Top N，提供明确的错误状态。限量摘要减少上下文开销。31题真实计划评测记录延迟中位数和P95；证据导读显示服务商返回的tokens用量，不据此虚构货币费用。

字段字典提供长度受限的释义、单位和最多 8 个别名；冲突别名被拒绝，别名只映射到原字段，不创造公式。定义同时用于本地演示匹配和真实模型上下文，单位只是显示标签，不自动换算数值。

模型必须调用 create_analysis_plan，输出维度、指标、sum/mean/count/min/max、日/月分桶、排序、展示条数、可选筛选条件和图表类型。Zod 检查结构，真实字段白名单检查指标和筛选。不存在的字段、不合法聚合和越界条数被拒绝。

模型不输出最终统计数字。浏览器执行确定性计划，再从真实结果生成说明，包含匹配数、有效数、排除数和极值；图表与报告复用同一结果。SQL 面板是口径示意，不执行任意 SQL 或模型代码。

连续追问发送 previousPlan，允许在原有指标与范围上修改聚合或维度。模型仍受相同结构与字段约束；演示模式仅在“改成、再按、只看”等有限表达中继承上下文。最多 8 项筛选按 AND 合并，同字段同操作符以新值替换旧值。

未接API时使用本地助手，在浏览器执行固定规则与确定性统计，不请求模型或分析接口。支持概览、质量、字段/字典说明、常用统计、连续分类筛选及数值上下界，计划先确认再应用。分类值从原表匹配，清除筛选不继承旧条件。未知字段、歧义、日期文字范围、比率、预测和因果不套用默认结果，提示明确口径或使用筛选面板。回答明确标识本地计算，不把固定规则称为模型生成。2026-10-26以个人DeepSeek deepseek-flash重新运行真实服务固定集，31/31通过；证据附带源码指纹，后续改动规划源码需重测。DeepSeek默认思考模式与指定工具调用不兼容，因此仅对官方端点显式关闭thinking，仍由真实模型生成受限计划；其他兼容端点保持原请求协议。

### 4.2 澄清与证据化回答

含糊的表现评价先选择衡量指标，相对时间先确认以数据最新日期为锚的时间范围；该澄清是本机规则，明确不同于模型推理。模型计划只在明确要求时新增筛选，missing操作仅表示空值，其value必须为空字符串。非日期分组不用timeGrain，允许只对这个无语义影响的空参数填入默认值；日期分组仍严格校验。

证据导读使用独立select_evidence工具，最多20项统计事实，模型只能选择最多6个有效事实编号以及预定义核查事项。程序检查引用存在且不重复；前端按原事实渲染数字、范围与来源按钮，避免模型自由编造数值和因果故事。摘要由浏览器产生，服务端只验证结构，没有原始表，因此不宣称服务端认证这些统计。用户点击后发送当前摘要，提供取消、失败重试和耗时/tokens说明。

### 4.3 业务知识检索与引用生成

用户可录入或导入TXT/Markdown定义，最多8份、单份24,000字符、总体96,000字符。段落切分后片段上限900字符，中文双字词项与英文词构建TF-IDF稀疏向量，用余弦相似度与词项覆盖率混合排序。未达命中阈值不调用模型，最多4段送给模型。不使用神经嵌入或外部向量数据库，不把检索分数称为置信度。

模型调用answer_with_sources，返回回答、answered/insufficient/conflict状态、片段编号和原句序号；程序从该原句填入引文。这样无需让模型复制文本，避免改写引文。程序仍检查编号、序号、无重复和逐字匹配；冲突需至少两个不同来源片段。显示版本、来源、完整片段、耗时与tokens。引文存在不证明回答语义一定受其支持，也不认证文档，用户仍须核对适用性和授权。

### 4.4 多步骤分析工作流

create_diagnostic_workflow生成合计指标、日期列、两个周期、1-3个文本维度与知识编号，工具以动态枚举约束列名。初次实测date被误填为具体日期，限定为列名后固定题通过。用户编辑并确认计划后，依次剖析当前范围、比较周期、分解各维度，再调用select_evidence选择已计算事实，导出完整报告。规划与导读各调用一次，不执行任意代码或开放式循环。

保留全局筛选，取消传递到请求和Worker。数据、字段定义、筛选或知识文档改变时中止旧任务，修改计划需重算。AI失败仍可核对和导出计算结果，可单独重试导读。每个维度分解同一总体差额，不能相加推导原因。比率和客单价使用独立计算器，不宣称自动因果推断或通用自主Agent。

## 5. 核心功能实现与前端交互

概览卡片及图表来自当前数据，可切换维度、指标、聚合和图表。表格支持搜索分页，质量页面查看各字段缺失与异常。助手通过 SSE 展示规划状态，支持取消与错误恢复，并可展开计算依据。

最近 30 次分析与文件保存于当前浏览器；报告包含来源、统计、聚合表、口径和限制。提供键盘焦点、可访问标签、模态框焦点约束及减少动画偏好支持。

### 5.1 联动探索与来源回溯

联动筛选同步更新 KPI、主图、分组图、构成图与预览，质量检查保持原始范围。图表点击或键盘可用的分组按钮打开来源明细，包含被排除的缺失指标记录，支持搜索、分页、CSV 导出和反向筛选。时间来源复用相同的日期分桶逻辑。

### 5.2 异常侦探与情景推演

异常检测使用线性插值四分位数，IQR=Q3-Q1，边界为 Q1-k×IQR 与 Q3+k×IQR；k 可在 0.5-3.0 调整。展示有效数、缺失数、中位数和边界，少于 4 条有效记录不判定。异常只作线索，不自动删除。

情景推演在当前筛选范围内，对全部或某一分类的单项数值指标做比例调整，显示原始与模拟合计、变化量、影响记录及对照图。模拟合计=基线合计+目标记录指标合计×调整率。创建数据副本，不改原表，不预测未来、不推断因果。

### 5.3 洞察收藏与同口径对比

最多保存 12 项配置，支持改名、批注、搜索、恢复、导出及删除撤销。结果从原数据重算；对比前要求维度、指标、聚合和时间粒度一致，无匹配分组保留 null，显示不可比，不冒充 0。比较范围限于各自展示的 Top N 分组。

### 5.4 下钻、成果报告与配置复现

来源明细可在保留当前分组的情况下继续按其他分类或日期字段分析；原指标和聚合方式保持，原历史不覆盖。离线 HTML 报告提供预览、SVG 条形图、完整聚合表、筛选范围、匹配/有效/排除数、字段字典和计算口径，支持浏览器打印。所有输入转义，CSP 禁止外部请求与脚本。

分析配置导出当前计划、收藏和字典，不含原始行，但会包含分类筛选值和批注。SHA-256 指纹绑定字段顺序及所有单元格内容，换了数据、行顺序或值即拒绝恢复；完整校验成功后才替换配置，原始数据和历史保持。该机制用于复现和防误用，不证明业务口径本身正确。

### 5.5 探索导航、计划确认和路线回放

探索导航根据当前筛选后的真实数据生成趋势、维度比较和缺失核对任务。缺失数量由本机重新剖析，建议不冒充模型推理；预览时保留原范围，新增条件不能越过八项限制。任务可转给当前助手，模型与演示状态始终可见。

默认进入计划确认：展示维度、指标、聚合、匹配与有效记录、筛选条件和本机试算。只有确认后才应用图表并保存分析；改变数据、筛选、字典或口径会使旧提案失效。模型建议与本机计算保持分离，用户可以放弃提案或关闭先确认选项。

探索路线记录当前数据最近二十步计划与筛选，在 IndexedDB 中保存；支持逐步恢复、2.4秒间隔回放与暂停。恢复旧步骤后继续编辑会截断后续路线并建立新分支；原有对话分析仍保留。换数据或清洗产生新副本时重置路线，拒绝跨数据恢复。回放重算图表，不生成新模型调用。

设置页提供真实模型连接验证，仅发送两行固定合成样本，验证工具调用及100/200的实际计算结果；有密钥只表示已配置，不能显示为已连接。取消提问向服务商传递中止信号。连接测试不能替代31题固定评测或证明通用准确率。

### 5.6 周期诊断与业务指标

用户选择本期、基期、日期字段、合计指标与分解维度，可用最新月份/上月或上年同期预设，也可自定义不重叠周期。比较保留全局筛选，并提示日期筛选可能截断周期。数据覆盖与两个周期天数不同均提示核查；零/负基期不提供增长率。按完整分组计算本期减基期的贡献，瀑布图合并其余组但保持差额守恒，表格预览最多100组、导出包含全部分组。来源按钮按周期和分组回到原记录。

业务计算器对成对完整记录计算合计比率，或金额合计除以去重订单标识数，展示公式、分子、分母、有效与排除记录。零分母不产生Infinity；利润率不是逐行利润率的平均值。数据上的贡献只描述变化构成，不能自动识别业务因果。

趋势图提供范围选择后确认应用筛选，保留其他范围条件。提供电商与校园合成场景、手机布局与模态焦点约束；v0.6.2精简了重复的新手提示。

### 5.7 诊断状态与保存指标

日期、指标、分组、两个周期、比率公式、显示方式、知识文档和工作流计划随工作区保存到IndexedDB，页签可恢复。切换页签保留参数，刷新恢复计划后需重算结果。新数据重置工具状态，撤销清洗恢复原工具状态，拒绝跨数据复用。日期监听input/change，已实际核对修改、跨页签与刷新恢复。

指标库最多12项，含名称、分子、分母、合计比率/去重标识数、显示单位与定义。只能引用当前数据有效字段，同名拒绝，随当前筛选重算。周期诊断导出含比率结果和定义，多步骤报告另列完整筛选范围指标，避免与比较周期混淆。

### 5.8 交互与阅读体验

v0.6.2放大正文、操作和图表标注，提高说明文字对比度。正文15px、常用操作14-16px、辅助文字至少13px；宽屏可显示三栏，窄窗口按需打开助手抽屉，手机使用四项底部导航。抽屉支持关闭、遮罩与Escape收起，矮窗口减少重复信息和留白，保留对话列表的滚动空间。

移除实验室旁的收藏计数、页签栏右侧重复导出、静态下拉装饰与重复引导。图表排序和时间设置按需展开，计数时隐藏无关指标；字段、统计方式和图表类型改变时同步更新标题。数据集卡片直接进入数据预览；无API时提供可操作的配置入口，保留本机分析。

### 5.9 交互图表与数值核验

主图、分组图和环形图复用共享组件，采用按名称稳定分配并在同图内避开重复的配色、渐变柱、明确坐标与精确数值提示。支持放大窗口、图表与分组明细切换、数值标签、明细独立排序和分组CSV导出；导出保持明细当前顺序、单位、有效记录与原始数值精度，不修改统计计划。放大窗口使用原生模态对话框，保留键盘操作、Escape关闭与来源跳转。窄屏拥挤标签隐藏，表格保留横向滚动，避免缩小字体或拆碎日期。

## 6. 安全与复现

公开网页采用访客自备API：密钥只保留在当前页面内存，刷新或关闭清除，不写入IndexedDB、localStorage、URL或工作区导出。密钥通过HTTPS请求头到本站，再临时转发所选官方服务；应用不主动记录或持久保存。服务器不使用部署者环境密钥兜底，公开环境已移除共享密钥。公开转发只接受预设的DeepSeek/OpenAI官方HTTPS端点，不接受任意URL，所有模型请求禁止跟随重定向。请求大小、问题长度、字段数和计划枚举受限；模型生成代码从不执行。文本由 React 转义；CSV 导出防护公式注入，同时保留合法负数。

模型仍会收到字段摘要与部分分类值，不将方案描述为零泄露。用户需有权使用数据。默认零售数据为固定随机种子生成的合成样本，含 1,251 行、6 个缺失和 3 条重复，可重复生成与核对。

保留依赖锁、环境变量模板、测试脚本与真实提交；不事后伪造开发历史。在线页面公开，无需登录；图表和本机分析直接体验，真实AI需评委自行接入个人API与额度。

五个模型接口共享单实例尽力频控：每个来源每分钟最多12次、最多2个并发；记录数有上限，结束时幂等释放。跨来源浏览器请求被拒绝，同源请求允许。这不是跨实例分布式限流或账户费用硬配额，不能保证公开开放后的费用上限。新模型工具不跟随重定向，凭据不转发给其他端点。
