# v0.6 分析路线与业务知识验收

日期：2026-10-25。队伍：疯狂星期四。更新范围为诊断恢复、指标库、多步骤助手、知识检索引用及调用控制。学校成员、实际MP4和真实用户试用仍待补齐。

| 功能 | 实现 | 验收边界 |
|---|---|---|
| 诊断恢复 | 周期、字段、比率与页签保存 | 切换和刷新恢复；绑定数据；恢复计划后重算 |
| 指标库 | 最多12项公式、单位、说明 | 真实字段、同名拒绝、成对完整记录；当前全局范围计算 |
| 多步骤助手 | 模型规划、确认、剖析、两期比较、1–3维分解、导读、报告 | 合计周期变化；保留筛选；取消中止；贡献不是因果 |
| 业务知识 | TXT/Markdown、分段、TF-IDF余弦与词项覆盖检索 | 本机稀疏向量，无神经嵌入或外部向量库；最多4段送模型 |
| 引用问答 | 真实模型回答、状态、编号与原文 | 逐字校验；冲突至少两片段；语义与适用性仍须核对 |
| 调用控制 | 同源校验、单实例12次/分钟、2并发 | 尽力限制，不是分布式限流或费用硬配额 |

## 验证

109项业务测试加7项仓库验证，共116项。新增27项覆盖持久化隔离、字段校验、原文引用、无命中、冲突、范围、报告、取消和限流。严格类型检查与生产构建按最终源码执行。

新固定集10项，9项调用DeepSeek，1项为本机无命中检查。4项规划核对销售差额3990、利润差额399、华东差额80及知识辅助计划；5项问答核对利润率、订单去重、退款、冲突和依据不足。原31题证据仍匹配未改动的普通规划源码，小样本不代表通用准确率。

浏览器20,000行合成性能样本，16,539条全局范围，两个维度均得基期2,036,235、本期2,001,435、差额-34,800；渠道线下-84,750、线上49,950。来源与AI事实使用对应范围。日期2026-06-15和保存指标经切换、刷新恢复；390像素无页面横向溢出，表格内部滚动。

发现并修复：日期列误填为日期值，增加列名枚举；模型复制引文偶有改写，改为选择原句序号并由程序回填；手机表格容器溢出；日期input更新未及时同步，补充input/change处理。HTTP核对同源允许、跨来源拒绝、非法输入和真实模型三类接口。

## 建议演示路线

1. 导入8行Excel样本，选择第二行表头与文本订单编号。
2. 选择利润/销售额保存“利润率”，修改周期、切换与刷新核对保持。
3. 智能分析添加授权业务定义，或载入明确标注的教学示例。
4. 询问利润率口径，打开引文；输入无关问题，确认无依据不请求模型。
5. 输入“对比2026年2月与1月的销售额合计，按地区和产品类别拆解变化”。
6. 核对计划并执行，两维差额均3990；华南来源中找到4000的记录。
7. 查看AI事实及核查事项，导出报告，说明贡献不证明因果。

真实试用按docs/用户试用任务.md邀请3–5名目标用户，记录原话、用时及是否需要提示，不预填效果数字。
