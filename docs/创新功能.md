# 创新功能与演示依据

这些功能围绕赛道允许的“AI 数据分析与可视化”方向，强化模型规划之后的数据探索、结果解释与应用交互。它们提供可演示的实现依据，不代表主办方已确认合规或评分。

| 功能         | 用户动作与结果                                      | 对应实现                                            | 评分关联               |
| ------------ | --------------------------------------------------- | --------------------------------------------------- | ---------------------- |
| 联动探索     | 添加地区、日期、指标范围；KPI、三张图和预览同步变化 | 受限条件校验、AND 合并、全局数据范围                | 实用性、体验、前端工程 |
| 来源回溯     | 点击分组检查每条记录，再联动到该分组                | 日期分桶与分类匹配复用计算规则；保留缺失指标来源    | 创新性、可信结果、体验 |
| 异常侦探     | 选择数值字段并调整阈值，查看异常记录                | 线性插值四分位数、IQR 边界、有效样本门槛            | 创新性、专业应用       |
| 情景推演     | 给目标分类的指标增加或减少一定比例                  | 不修改原表；生成副本并重算，同步对照图              | 创新性、交互与实用性   |
| 洞察收藏对比 | 保存范围与口径、批注、恢复和比较                    | IndexedDB 持久化；相同计算口径校验；无匹配保持 null | 实用性、体验           |
| 连续追问     | 在已有结果上改变聚合、维度或分类范围                | previousPlan + Function Calling；前后双重字段校验   | AI 深度、体验          |

## 可手算样本

v0.4 补充三项交互：探索导航根据当前范围推荐实际可执行任务；助手默认先展示受限计划和本机试算，由用户确认应用；探索路线支持二十步快照、回放、暂停和恢复后分支。它们与来源溯源、情景推演、配置指纹配合，强化分析过程的可核验性。导航使用本机数据规则并如实标识，不能当作真实模型验证。

上传 `docs/samples/innovation.csv`，含 8 条合成记录、6 个字段。切换数据会清空旧数据的分析与收藏，避免跨数据误用。

1. 销售额依次为 100、110、120、130、140、150、160、4000，合计 4910，利润合计 491。
2. 异常检测销售额：Q1=117.5，Q3=152.5，IQR=35，1.5 倍阈值的下界=65、上界=205；只标记 4000。
3. 情景推演选择地区=华东、销售额+10%：华东原合计 500，增加 50，总模拟值 4960。0% 时恢复基线 4910，原表始终保持 8 行。
4. 连续提问“各地区利润合计”“改成均值”“只看华南”：保留利润与均值口径，华南 4 条、利润合计 441、均值 110.25。
5. 收藏全部范围与华东范围下的同一月度销售分析，查看同口径对比；更换为利润指标后会提示不可比。

## 计算与交互边界

- 最多 8 个筛选条件；相同字段与操作符的新增条件替换旧值，范围上下限可同时存在。
- 质量检查针对原始文件，异常检测与情景推演针对当前筛选范围。
- 异常不等于错误，不自动清洗；有效记录不足 4 条时提示样本不足。
- 推演统一使用合计，不依据指标变化推断其他变量，也不对未来作预测。
- 收藏保存配置，结果从当前原始数据重算；导入新数据或清洗会清空旧收藏，清洗撤销会恢复。
- 连续追问是基于上一轮计划的上下文处理，不宣称无限多轮推理。无密钥时使用明确标记的有限规则；真实模型固定集已于2026-10-23通过6/6，更多业务场景仍需验证。
- 本版本不宣称向量 RAG、多 Agent、MCP、多模态或自训练模型。新增计算与交互均有独立源码，不依赖隐藏服务完成统计。

## 赛事材料建议

在 5-8 分钟视频中重点展示“提问 → 筛选 → 来源 → 异常 → 模拟 → 收藏对比”闭环。技术文档注明每一步的字段、样本范围、计算方法与限制。源码及 Git 历史如实提交，录制前完成真实模型测试和评审访问准备。
