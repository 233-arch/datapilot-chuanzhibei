## 使用真实 AI

1. 打开“工作空间设置”，或点击“配置我的 API”。
2. 选择 DeepSeek 或 OpenAI，填写自己的 API Key 与支持 Chat Completions 工具调用的模型 ID。
3. 点击“应用并验证我的 API”。会使用个人账户额度，以两行合成样本验证，不发送当前表格。
4. 继续使用对话规划、多步骤助手、知识问答与证据解读。模型账户、地区可用性、额度与工具调用支持由服务商决定；目前真实回归使用 DeepSeek，未实测 OpenAI 服务。
5. 使用后点击“清除 API 配置”；刷新或关闭页面也会清除。

个人配置仅保留在当前页面内存，不写入 localStorage、IndexedDB、URL、数据集、报告或配置导出。密钥通过 HTTPS 到本站，临时转发给所选官方服务商；应用不主动保存或记录凭据。本站不提供共享额度，不使用部署者密钥作为缺省值，托管环境的共享密钥已移除。

为限制公开转发范围，网页仅支持预设的官方 HTTPS 端点，不接受任意 API 地址；所有模型调用禁止跟随重定向。同源检查与单实例尽力频控继续生效，不是全局费用硬配额。

## 验证与边界

`node scripts/test-visitor-api.mjs` 检查环境密钥不兜底、访客隔离、固定端点、非法凭据及无配置请求头。

启动服务后，`node scripts/test-visitor-http.mjs` 检查匿名页面、三个静态资源、无个人凭据时的四个AI接口拒绝，以及任意服务地址拒绝。加 `--with-api` 时从本机忽略文件读取评测密钥，仅供当前进程的个人请求，额外验证真实连接、规划、问答和导读，不将密钥写入证据。

设置 `DATAPILOT_TEST_URL` 指向在线地址，并将 `DATAPILOT_DEPLOYED_COMMIT` 设为实际部署的提交号，再运行上述验证，可生成绑定该部署的匿名访问证据。提交审查不会仅凭手填地址与时间判定通过。
