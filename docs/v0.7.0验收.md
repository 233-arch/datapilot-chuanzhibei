# v0.7.0 工作台与数据交互验收

核对日期：2026-11-07（Asia/Shanghai）。本次修改保存在本地工作区；按用户最新要求暂不处理 Sites 连接，不执行线上发布。

## 改动

1. 工作台使用浅灰背景、白色卡片与绿色品牌重点，强化选中标签和文字对比度。新增区域主体文字为 14–16px；移动端保留双列指标卡与底部导航。探索历史置于当前工具下方，可展开恢复、回放。
2. 数据预览支持全字段搜索、三态排序（升序、降序、原始顺序）、显示列选择和分页条数。数值按数值比较，日期按有效日期比较；无效类型值与空值始终放在末尾，相同值保持稳定顺序。
3. 导出按当前筛选范围、搜索、排序和显示字段生成 CSV，包含全部匹配记录。行号表示当前范围的原始位置；隐藏字段仍参与搜索。零记录禁用导出，保留清空搜索入口。
4. Ctrl/Cmd + K 打开功能搜索。方向键选项自动滚入视野，Enter 执行，Escape 关闭；已有导入或图表模态窗口时不再叠加搜索。工作台标签页支持方向键、Home/End。
5. 图表选中反馈包含完整值、有效记录数和来源入口，恢复按钮清除选择。时间区间选择支持重置；无法表达占比的饼图提供明细入口；明细固定首列并支持键盘横向滚动。
6. 本机恢复失败时停止编辑与自动保存，保留重试入口；保存失败明确提示，可重试。过期保存回调不会覆盖新状态。弹窗重新渲染不会反复抢走输入焦点。

## 预评分反馈后的功能补强（2026-11-10）

用户提供预评分 73，完整评语为“基础架构和润色文章”。此评语没有分项扣分或测试记录，以下是团队主动补强的内容，不声称为评审明确指出的问题，也不预测提分结果。

### 可操作的质量核验流程

新增“问题记录定位”，置于质量摘要之后。缺失、数值/日期类型异常、整行重复均可按类型和字段筛选；记录序号对应整个当前数据集，不受分析筛选影响。重复记录标明首次出现的记录序号，可展开完整记录核对上下文。问题清单可导出 CSV，并保留公式转义。

清洗弹窗增加执行前后预览：记录数、重复记录、缺失单元格、无效值与修整数量。执行使用同一预览结果，避免展示口径与实际修改脱节。没有变化时禁用执行；保留原有撤销入口。文本空值标记只作用于文本字段，数值和日期保持空值，清洗后固定原字段类型，避免重新推断改变分析口径。

### 修复和工程边界

- 日期类型字段此前只检查缺失，没有统计非法日期；现已纳入无效值统计。
- 部分运行时会把 ISO 的不存在日期自动滚动到下个月，现先验证年月日，再验证时间戳。
- 空数据集的字段完整率显示不再除以零。
- 纯计算和界面分离为 `lib/quality-audit.ts` 与 `components/exploration/quality-audit.tsx`。
- 页面最多保留 200 项问题证据，计数仍覆盖全部记录。导出最多 50,000 项，超出明确要求按字段或类型分批，不静默截断。
- 不自动修改非法值；文本标记不代表补回真实数据。质量检查通过不代表业务正确。

## 多页面与任务导航（2026-11-10）

按照“增加互动性、不要把功能堆在一个页面”的要求，将工作空间拆成九个独立视图。工作台首页集中展示指标和任务卡，原概览的图表与计算依据移入图表分析页；数据明细、质量检查、诊断、智能分析和实验室直接出现在主导航。报告与数据集继续使用各自页面。

每页拥有独立的 hash 地址，并与浏览器前进后退同步；首次打开时优先使用有效的地址页面，等待本机数据恢复后再导航。地址不携带原始数据、筛选内容或 API 凭据。桌面导航分组，手机提供四个常用底部入口和包含全部页面的选择器。首页任务卡与页尾后续操作形成页面之间的流程。
