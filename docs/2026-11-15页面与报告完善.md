# v0.7.0 本地页面与报告完善

本轮聚焦报告交付流程和页面模块的可维护性。修改保存在本地，没有发布在线站点、推送 GitHub 或替换参赛压缩包。

## 已完成

1. **报告编排页面**：用报告封面、组成摘要、质量依据和分析卡片组织内容。提供明确的预览、导出、打开图表、核对来源入口；手机端自动调整为单列。
2. **自主选择报告内容**：当前图表、收藏、历史分析合并重复项，保留批注与分析来源。支持单项勾选、全选、取消全部；未选择时禁用预览与报告导出。一份报告最多 30 项。
3. **页面和导出使用相同选择**：HTML、Markdown 共用报告目录与选择逻辑。按当前数据重新计算，保留每项独立筛选条件、有效记录数、排除数、单位与计算口径。
4. **规则检查接入完整报告**：展示规则条件、已检查/通过/违规/跳过数量和通过率。规则检查完整数据集，与图表筛选范围明确区分；未配置或没有可检查记录时，不声称已通过。
5. **预览与文件一致**：预览窗口的 HTML 导出使用该次预览快照，不在点击时重新生成时间和内容。Markdown 增加字典、批注与来源说明，并处理用户文本中的 Markdown/HTML 标记和 SQL 代码围栏。
6. **组件拆分与错误恢复**：报告页面拆到 `ReportCenter`，目录和导出组合逻辑拆到 `report-bundle`，质量摘要由 `ReportQuality` 负责。页面内容增加 `PanelBoundary`，模块渲染异常时提供重试和返回工作台，保留父级工作空间状态与导航。

## 如何演示

1. 打开图表分析，收藏一项分析，再切换另一个分组。
2. 进入洞察报告，查看当前图表与收藏；取消一项，预览确认报告只包含剩余内容。
3. 展开规则摘要，查看已定义条件和真实统计；点击核对入口回到质量检查。
4. 在报告卡片打开图表或来源明细，核对计算使用的记录。
5. 导出 HTML 或 Markdown；HTML 可以离线打开并通过浏览器打印为 PDF。
