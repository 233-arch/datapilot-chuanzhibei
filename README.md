# 数问 DataPilot

面向传智杯 **AI WEB 网页开发挑战赛**“AI 数据分析与可视化”方向的可运行作品。

**让大模型理解问题，让确定性计算回答问题。** 上传 Excel / CSV，用自然语言生成可检查的分析计划；数值由浏览器中的受限聚合引擎计算，展示参与记录数、缺失排除与计算口径。

## 已实现

- CSV / TSV：UTF-8 BOM、中文编码回退、引号/逗号/换行单元格、空值、输入限制；最多 25 MB、20,000 行、80 列。
- 数据概览：实际统计、月度趋势、分组对比、构成图，可切换维度、指标、聚合与图表类型。
- 表格搜索、分页、CSV 导出。
- 质量检查：缺失、无效数值、完全重复；清洗与撤销。
- 分析助手：字段摘要检索、Function Calling、Zod/字段白名单校验、确定性执行、SSE 状态、请求取消、分析证据。
- 本机 IndexedDB 保存、最近 30 次分析、Markdown 报告导出。
- 桌面三栏、移动端助手抽屉、键盘操作与可访问标签。

## v0.6 分析路线与业务知识

- **多步骤助手**：生成真实模型计划，确认日期、合计指标、1–3个维度后，逐步剖析、周期比较、贡献分解、证据导读与完整报告。修改上下文取消旧任务，不把贡献称为因果。
- **诊断恢复**：自定义周期、字段、比率公式、页签自动保存在本机，切换与刷新后恢复；计划恢复后重算结果。
- **指标库**：最多12个合计比率或金额/去重标识数，保存定义与单位，按当前筛选重算。
- **知识问答**：导入TXT/Markdown，TF-IDF稀疏向量与词项覆盖检索，引用可打开原文；冲突、依据不足明确显示。
- **调用控制**：同源校验，单实例每来源12次/分钟、2个并发；不是全局费用硬配额。
- **验证**：新增27项业务检查；9项真实DeepSeek调用与1项无命中检查通过。真实用户试用未执行。

复现见 [v0.6验收](docs/v0.6验收.md)，真实评测执行 node scripts/eval-intelligence.mjs；HTTP核对执行 node scripts/test-intelligence-http.mjs。

## v0.5 可信业务诊断

- **先澄清口径**：对含糊的表现评价与相对时间提供选择；时间锚定数据中的最新日期。
- **AI证据导读**：发送受限统计事实，由真实模型选择事实编号和核查事项。程序拒绝不存在或重复的引用，显示数值与来源入口，并记录tokens与耗时。用户字段摘要未经服务端原表重算，不宣称服务端认证统计。
- **周期对比**：最新月/上月、最新月/上年同期和自定义周期；完整分组贡献瀑布图、差额表、来源记录及诊断导出。核对零/负基期、空周期、覆盖缺失和全局筛选；不将贡献解释为因果。
- **业务指标**：匹配完整记录的合计比率、金额/去重订单数，明确公式、有效记录、排除项和零分母处理。
- **导入向导**：XLSX工作表选择、表头行预览、类型校正；保留文本编号与日期，支持文本百分比转换。只导入一张表；不重新计算Excel公式。
- **交互与性能**：趋势图范围选择后应用全局筛选；新手引导、电商/校园合成场景；导入、剖析、周期分解通过可取消的Web Worker执行。
- **验证**：82项业务测试与7项仓库测试；31道真实计划题通过，另有真实证据解读核对；20,000行固定样本Node Worker基准有独立记录。实际用户试用尚未执行。

## 连接真实模型

无API时显示**本地助手**，概览、质量、字段说明、常用统计及筛选均在浏览器执行；明确标为本地规则，不是大模型推理。预测、因果和未识别的条件返回能力范围及操作入口。

网页中打开“工作空间设置”，选择 DeepSeek 或 OpenAI，填写自己的 API Key 和支持工具调用的模型 ID，点击“验证并应用我的 API”。通过后才应用；失败时保留原配置。配置仅在当前页面内存中生效，刷新或关闭即清除，不写入浏览器存储，也不进入数据集、报告或配置导出。密钥经本站 HTTPS 服务临时转发至所选官方服务商；本站不主动保存或记录请求密钥。可随时点击“清除 API 配置”回到本地演示。

所有网页 AI 路由仅读取当前请求的个人凭据，不使用部署者的环境密钥作为后备。公开转发仅接受预设官方 HTTPS 地址，不接受任意服务地址，也不跟随重定向。OpenAI 选项的实际可用性取决于访问者模型的 Chat Completions 工具调用支持，当前真实服务回归使用 DeepSeek。

以下环境模板仅用于在本机运行独立评测脚本，不能为网页访客提供共享调用：

```dotenv
DATA_MODEL_API_KEY=仅在本地填写，禁止提交
DATA_MODEL_URL=https://api.deepseek.com
DATA_MODEL_NAME=deepseek-flash
```

本机评测适配器需要支持 `tools` / `tool_choice` 的 Chat Completions 服务。基础 URL 不含 `/chat/completions`；供应商需要 `/v1` 时包含 `/v1`。公开托管环境已移除共享模型密钥。

真实服务证据见 `docs/evidence/deepseek-evaluation.json` 与 `docs/evidence/intelligence-evaluation.json`，均绑定对应源码指纹；这是固定合成样本回归，不代表通用准确率。DeepSeek 官方端点为指定工具调用显式设置 `thinking: { type: "disabled" }`，其他兼容服务不发送此专用字段。评测密钥仅在本机忽略文件中配置；网页使用访问者本页内存中的个人 API。

## 数据与限制

- 默认数据是固定种子生成的**合成数据**，1,251 行、6 个缺失单元格、3 条完全重复记录，不是真实企业数据。
- 完整文件和历史保存在当前浏览器，不跨设备同步；清除浏览器存储或更换域名会重置。
- 模型模式发送问题、字段名、类型、统计摘要与部分分类值，不发送完整表格。常见敏感字段值会过滤，但这不等于正式脱敏。
- 不执行模型生成的代码或任意 SQL；SQL 面板仅为口径示意。
- 图表助手的字段匹配仍为关键词；业务知识问答使用本机TF-IDF稀疏向量混合检索，最多4段送入真实模型，并校验原文引用。没有神经嵌入、外部向量数据库、多模态、MCP 或多 Agent。
- 支持单表 XLSX / CSV / TSV；旧 XLS 需另存为 XLSX。不支持 Join、预测、因果推断与多人云同步。
- 在线页面公开访问；真实 AI 需评委自行接入 API，未配置时可体验本机分析。评审期间应保持托管服务可用。
